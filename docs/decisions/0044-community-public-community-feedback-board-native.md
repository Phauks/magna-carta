**Public community & feedback board — native build on Cloudflare (supersedes the deferred-Fider lean).** A wanted feature: cross-firm public discussion, **feature voting**, known-issues, and roadmap/changelog, tied to bug reporting (_Observability and diagnostics_) and the help center (_User-facing documentation_). **Decided now:** the forum is **platform-level, public, cross-firm, opt-in/user-authored, and never touches per-firm or privileged data**; integration is native **SSO** + a one-way **escalation bridge** from private _Observability and diagnostics_ reports. **Per-tracked-user pricing (Canny) rejected** — reproduces the per-seat cost-scaling the platform exists to escape. Caveat: a public forum is a permanent moderation / spam / security-patch commitment regardless of host. **Amended 2026-06-17 (delivery decided — native build):** a 2026-06-17 changelog/feedback-tool survey made the Fider lean the weakest part of the plan — Fider needs **Postgres + mandatory SMTP**, is **AGPL-3.0**, and ships **no changelog and no roadmap/kanban UI**; none of that fits the Cloudflare per-firm D1/R2/Workers + Cloudflare-email stack, and its actual surface is small enough (posts → votes → comments → tags → 6 statuses → 3 roles) that a **native build is less work than operating an off-Cloudflare host**. **Decision:** build natively as a clean, extractable **`@magna-carta/community`** package (the government-links / property-links pattern) on **control-plane D1 + Cloudflare email**, isolated from the per-firm DAL so the isolation _is_ the confidentiality boundary. **Board now** (feature requests + upvote + comments + status pipeline + roadmap-as-filtered-view-by-status), with a **dormant `discussion` seam** for an open forum later; **display-name identity** (real name/firm never shown publicly, aggregate vote counts only, admins see the real account); the loop is **subscriber-carry + Cloudflare-email notify on ship**, never auto-authored prose (preserves ADR-0048 version-accuracy by construction). Hosted options (UserJot/Featurebase) and Fider all rejected for the Cloudflare/confidentiality mismatch. **Implementation deferred until Fable is available again.** Design spec: [`docs/specs/2026-06-17-community-feedback-board-design.md`](specs/2026-06-17-community-feedback-board-design.md).
