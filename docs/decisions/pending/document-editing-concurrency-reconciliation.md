**Document editing concurrency & reconciliation — optimistic, never-block, human-reviewed.** **Decision:** the per-document Durable Object is the single authority over three access intents, under three invariants — **reading is never blocked**, **no work is ever silently lost or merged** (every merge is human-reviewed), and **one isolated container per document**. **Online** editing is real-time co-editing: connected editors share one Collabora session and **one** WOPI session lock (first editor locks, co-editors join, last leaver unlocks); a second editor **joins**, never blocked. **Read** is always available — a viewer joins read-only (write hard-rejected server-side) or gets the last committed version. **Offline** editing is optimistic and never blocked: checkout hands back a short-TTL **presigned GET** (key server-derived, ADR-0081/0082); check-in returns through the **ADR-0081 quarantine ingest path** (untrusted bytes — scanned before any container opens them); on a cleared check-in, divergence (by base-version-id + hash) either fast-forwards or is kept as a **conflicting copy** + a `needs reconciliation` flag, resolved by a human `documents:reconcile` decision (**no automatic `.docx` merge**; the conflicting copy is retained forever). An **opt-in exclusive lock** lets a member prevent divergence (others still read). **Stale locks:** a dead co-edit session is reaped fast by an alarm heartbeat (~60–90 s; 30-min WOPI expiry is only the backstop); a deliberate exclusive lock gets a **generous, firm-configurable idle auto-release + manual force-release** (authority matter-team-with-edit + firm admins/owners, **matter-scoped** so an ethical-wall exclusion denies it even for a firm admin; force-release is always safe). The §4 revocation explicitly **does not recall** an already-downloaded offline copy — a revoked member's check-in is refused and the checkout force-released. **Rejected:** pessimistic exclusive-lock-by-default (blocks people; the owner red-flagged the "locked out by a ghost" failure mode); automatic merge of diverged `.docx` (not line-mergeable — reconciliation is human-reviewed); a decomposed/structured doc model to enable merge (ADR-0010, fidelity). Builds on ADR-0035 (versioning), ADR-0081 (quarantine ingest), ADR-0068/ADR-0052 (access control; within-firm 403 vs absence 404), ADR-0049 (deleted-file lifecycle).
