**Magnus context is granted per conversation; access seeds to the four working roles; transcripts are work product with an explicit discovery include/exclude control.**

**Context:** The merged Magnus design (docs/specs/2026-08-06-magnus-design.md) flagged model choice,
access scope, context boundary, and transcript retention. Slice 1 builds flag-free; these answers
shape slice 2 and the discovery interplay.

**Decision:** On 2026-08-06 the owner ratified F3 (explicit per-conversation grants) and F2
(Owner/Admin/Attorney/Paralegal) as recommended, and answered F4b in their own terms: transcripts are
"more like work product, so I would say protected, deletable, archivable. discoverable like email but
the search/discovery should allow for if it should be included or not." The work-product framing
replaces the correspondence-retention default: transcripts carry the protections and lifecycle of
work product, and every search or discovery corpus that could include them must ask.

**Consequence:** Slice 2's shape is set (grant records on the conversation, visible in the
transcript). Discovery 5·1·2's load sources and any transcript-reaching search scope gain a required
include/exclude control. F1 (model choice) remains open until production enablement.
