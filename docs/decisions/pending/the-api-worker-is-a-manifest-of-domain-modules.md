**The api worker is a manifest of domain modules, not a flat list of route files behind one composition root.**

**Context.** `apps/api-worker` holds 105,148 source lines, 74,765 of them in a flat `src/http/routes/` of 99 files defining 714 routes and 631 operations. The four largest route files are over 3,000 lines each, and the weight is contract shape built at module scope (453 `z.object` constructions, 891 named components), not business logic, which already lives in the domain packages. `app.ts` is at once the composition root, the single home of the `Bindings` type (imported by 88 non-route files) and a manifest of about 116 registration calls whose order Hono treats as load-bearing. The startup budget was crossed once (2026-08-31); the dynamic-import fix moved the cost to the first request in each isolate, where it grows linearly with routes and is unmeasured. Three registries outside the modules must be touched for every route: a hand-maintained list of 631 operation ids, a 524-line area note, and a 3.1 MB snapshot regenerated as one unit.

**Decision.** Each domain becomes a directory under the route tree with one `index.ts` that builds its own typed `OpenAPIHono` through `createDomainApp()` (the one place the validation default hook is set, so a sub-app cannot answer a validation failure with anything but the 422 problem document), registers its routes exactly as today through `chokepointMiddleware` (so the registration-time meta assertion and the permission check still throw at startup), and is mounted at `/` by `app.ts`, which shrinks to the composition root plus a manifest. Paths stay absolute because domains do not map to path prefixes. Request and response shapes move to `packages/<domain>/src/contract.ts` as plain zod; the worker applies the component name at the route, so no domain package takes a Hono-family dependency. `Bindings` moves to `src/bindings.ts`. The tree splits into `src/http/` and `src/background/`, with the shared machinery between them, and a fitness test holds the boundary. The hand-maintained operation list becomes one list per module; the area note splits the same way.

**Guards.** The existing registration-time assertion, byte-exact snapshot and conformance suite carry the move; the migration's acceptance criterion at every step is a document identical to today's after a canonical key sort. Four repo-wide fitness checks are added: a route table (every operation's method and path template resolves through Hono's router to the handler carrying that operation id, which is what makes a shadowed route fail by name), route hygiene (no direct `OpenAPIHono` construction, every `app.openapi` carries the chokepoint middleware, no cross-domain module import), per-file caps on lines and schema constructions with an allow-list that only shrinks, and the import boundary. `wrangler check startup` joins the gate as a recorded trend, not a threshold.

**Considered and rejected.** Lazy per-domain loading on first request: at the pinned Hono 4.13.0 the default router throws once its matcher is built, so a domain cannot be mounted into a live app, and a prefix cannot select a domain; the workable shape (a per-domain app behind a dispatcher, plus a second eager composition for the emitter and the suites) is deferred until the recorded startup trend justifies it. A background Worker: settled 2026-08-21 in the extraction rubric (routes address six of nine job coordinators; `runInDurableObject` binds 28 test files to this Worker) and not reopened; the in-repo seam keeps it cheap. Splitting the generated client by tag: it is generated, not hand-maintained, and the pinned generator has no per-tag output.

**Consequences.** A new surface is one directory and one manifest line, with its rules beside it; the shape of what a domain's API accepts lives with the domain; a regrowth fails a named test rather than a review. The cost is a one-time reordering of the committed snapshot and client, a series of contract-move pull requests tracked by the allow-list, and a second composition to write later if lazy loading is ever earned.
