**Collabora editing — WOPI host, per-document hosting topology, and access-token auth.** **Decision:** in-app `.docx` editing runs Collabora Online (coolwsd) in **one isolated Cloudflare Container per open document**, coordinated by a **per-document Durable Object** (`DocumentSession`, addressed by `fileId`, durable state in `ctx.storage` SQLite). We are the **WOPI host**, Collabora the client; the host is built to the **standard `X-WOPI-*` contract as the baseline** with Collabora's `X-COOL-WOPI-*` extensions **additive**, keeping both Word futures (Office-for-web client; desktop-Word check-out) reachable. WOPI callbacks are a **token-authenticated surface off the cookie chokepoint**: a short-lived HMAC-signed capability (per-firm-derived signing key + `kid`, `sessionId`-bound, constant-time verify) whose firm-scope **and** capability are **re-derived/re-checked at use on every callback** (a firm-A token against a firm-B `WOPISrc` → 404; a view token cannot `PutFile`/`Lock`, server-side, independent of the advisory CheckFileInfo flags). Near-instant revocation rides a sub-ms DO `member.status` check **scoped to genuine permission-change** (in-flight `PutFile` allowed to complete; routine expiry via `access_token_ttl`). coolwsd runs **least-privilege**: no egress, no R2/D1 credentials or key material (all object I/O through the token-authenticated host), ephemeral per document. The editor iframe is served from a **dedicated cookieless origin** with a `postMessage` origin allow-list; the ADR-0029 preview-sandbox does not apply (a trusted derived renderer; raw bytes never reach the browser). Container WS keep-alive (#147/#162) is **alarm/host-driven, never WebSocket-frame-driven**, with durable reconnect (state in DO SQLite + R2 → zero lost work). **Rejected:** pooled/shared coolwsd (one process serving many documents — blast-radius + cross-firm-in-one-process, owner red-flag; the ~$8–100/mo amortization does not justify it); a hand-rolled per-`fileId`-claimed warm pool (collides with `getContainer(binding, fileId)` keying — use native `min_instances` pre-warming instead); a second native CRDT/structured editor (ADR-0010, fidelity). Builds on ADR-0010 (editor choice), ADR-0067 (chokepoint), ADR-0066 (OpenAPI contract; WOPI routes via the conformance allow-list), ADR-0046 (key-versioning), ADR-0075 (resource naming), the security-conventions untrusted-file bar, and ADR-0029 (preview origin).
