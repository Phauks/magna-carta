**Time tracking — the daily driver, built deep:** speed/keyboard-first capture via a **single active live timer** with **server-side state that persists across tabs/devices and offline (Tauri) then syncs**, plus manual entry, a **weekly timesheet grid**, and one-click **calendar-derived** drafts. Entries carry resolved **effective-dated rates** (matter → client → timekeeper → role; multiple rate cards), **configurable increment/rounding** (default 0.1 h), narratives with snippet/template assist, and optional **UTBMS codes**. **No approval workflow** — Draft (editable) → Billed (locked), append-only corrections after. **Time is WIP, not a ledger posting** (converts to A/R at invoicing). Daily-driver features: "My Day" totals, **missing-time detection**, billable **targets**, utilization/realization into Reports. **Passive/automatic capture stays backlogged.** **LEDES e-billing promoted to v1:** export **LEDES 1998B + XML 2.0/2.1** with UTBMS task/activity/expense codes and **client-billing-guideline validation**; expenses carry UTBMS **E-codes**.
