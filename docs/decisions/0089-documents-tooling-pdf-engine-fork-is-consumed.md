**The PDF-engine fork is consumed as `pnpm pack` tarballs of our built `@embedpdf/*` packages (vendored, `file:` deps) — not `pnpm patch` and not a live git dependency — and collapses to the published npm version once the upstream PRs merge.** **Context:** ADR-0088 §J set the upstream-first policy (ship locally in parallel; collapse on merge) but left the _consumption mechanism_ open. The sanitization contribution ships a custom-built **PDFium WASM binary** (~4.6 MB) plus TypeScript living in pnpm-workspace subpackages, which rules out the casual options. **Decision:** consume the fork via `pnpm pack` tarballs of our built `@embedpdf/pdfium` + `@embedpdf/engines` + `@embedpdf/models` (each `.tgz` bakes in the built `dist` **and** the rebuilt `pdfium.wasm`), vendored into the repo and depended on via `file:` (or a private registry) — reproducible, self-contained, and the only clean way to carry the binary. **Collapse** to the published `@embedpdf/*` version once the upstream PRs merge (issue embedpdf/embed-pdf-viewer#673; PRs embedpdf/pdfium#27 + #28, embedpdf/embed-pdf-viewer#674 + #675). **Fork-sync cadence:** on a PDFium bump, re-pull upstream, rebuild the wasm via the fork CI's `rebuild_wasm` path, re-pack; the ADR-0088 item-2 license gate covers the vendored tarballs (all permissive / weak-copyleft). **Considered & rejected:** **`pnpm patch`** (it diffs files; a multi-MB binary patch is unworkable); a **live git dependency** (the `@embedpdf/*` packages are workspace subpackages, not root-installable). **Consequences:** no live external git dependency at build time; a small vendored-tarball + fork-maintenance tax until the PRs merge, after which it disappears. **No consumption code lands until the first PDF product slice needs it** — this records the mechanism so that slice does not stall on it. **Status Accepted.** Refines **ADR-0088** (§J upstream-first); first exercised by the first PDF slice; signing follows its own path ([`docs/specs/2026-06-13-embedpdf-signing-options.md`](specs/2026-06-13-embedpdf-signing-options.md)).
