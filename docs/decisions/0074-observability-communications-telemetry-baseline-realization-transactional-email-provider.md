**Telemetry-baseline realization, transactional-email provider & dependency automation (slice 0·6) — the golden-rule-4 logging path lands as `@magna-carta/telemetry` (allowlist event builders that make redaction structural, a scrubbing-backstop tripwire, `cor_` correlation + `err_` Error IDs minted via the identifiers package, a pure `Logger` seam with a Workers adapter emitting structured JSON to Workers Logs + counters to Analytics Engine), enforced by a console-ban fitness function; the white paper's "bug-report Worker" is realized as `POST /v1/incidents` in the single Worker (ADR-0069 — one deployable) writing a per-firm `incident` row and an `incident.created` outbox→Queue message with no consumer yet (the diagnostics agent's future feed); transactional email is **Cloudflare Email Service** behind the existing `sendEmail` port via the native `send_email` binding (public-beta caveat accepted: DKIM/SPF runbook + the port seam are the mitigations; Resend and AWS SES rejected); dependency automation is **Renovate** (pnpm-catalog-aware, pin strategy, grouped weekly, propose-only per ADR-0058) + an OSV/audit CI gate + GitHub secret scanning.** **Context:** slice 0·6 builds the backend of the observability pillar (ADR-0017/0038) on a paid Workers plan (this slice's first paid dependency, owner-confirmed); the slice's roadmap scope was reshuffled during design because the client-reporter UI, diagnostics settings, and visual-regression CI have nothing to attach to before the design-system/auth-UI slice, and the diagnostics agent has nothing to consume before incidents flow. **Consequences:** ad-hoc logging fails CI; every error path carries a user-visible Error ID joined to its server trace by construction; Logpush→R2 and DKIM/SPF/Email Routing are deploy-time runbook steps; the UI slice inherits the reporter surfaces, breadcrumb library, screenshot capture, diagnostics setting, and visual-regression CI; incident descriptions move under `protected()` when the crypto module lands (named seam). **Rejected:** a separate bug-report Worker (second deployable against ADR-0069 for no present payoff); console-only minimal wiring (builds the exact habit golden rule 4 forbids); Dependabot (weak pnpm-catalog support); auto-merge dependency updates (upgrades stay deliberate). Spec: `docs/specs/2026-06-09-slice-0-6-telemetry-baseline-design.md`. _Amended 2026-06-13 (build, Opus during the Fable-access gap):_ (a) **Email Service API confirmed** — the public-beta Workers binding is a simplified `env.SEND_EMAIL.send({ to, from, subject, text, html })`, no mimetext; the adapter is selected only when both the binding AND an `EMAIL_FROM` var are present, with `EMAIL_FROM` the activation switch the operations runbook flips after `magnacarta.esq` is onboarded — so dev/test and a not-yet-onboarded production keep the logging adapter and no send fails. (b) **Audit gate is `pnpm audit --audit-level high`** with a documented `pnpm.auditConfig.ignoreGhsas` allowlist for two pre-existing TRANSITIVE dev/build-tooling highs (esbuild GHSA-gv7w-rqvm-qjhr, lodash GHSA-r5fr-rjxr-66jc), each dropping when Renovate upgrades its carrier. (c) The catalog grew beyond the original six: **`auth.denied`** (the platform-admin console.error denial-cause seam migrated onto the pipeline — the allowlist is the redaction), **`operation.failed`** + **`outbox.deadLettered`** (the background counterparts of `error.captured`, replacing the scheduled/sweep/auth-audit console.error seams so the console ban is honest), plus a `reconciliation.unprovisioned` counter. (d) The error boundary is `app.onError`, not an outer try/catch — Hono's compose routes a thrown handler there. (e) **`firm:reportIncident`** permission seeded onto every default role gates the incident route (`resource: firm` — no new resource type). (f) A 7-angle adversarial review (11 low-severity findings, zero high) fixed nine in-pass; two deferred as documented seams (the email per-send correlation id; the conformance resolver's allOf/oneOf handling). Runbook: `docs/conventions/operations.md`.
