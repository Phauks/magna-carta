**Product-usage analytics — measure which features are reached and completed, for us the builders, cross-firm.** **Context:** the platform has many surfaces and no signal on which are used; investment and cut decisions should rest on data, not intuition. **Decision:** add a `usage.feature` event category (`reached` — a user arrived at a feature surface; `completed` — a firm-level workflow finished) that rides the **one logging path** (ADR-0038/ADR-0017; `@magna-carta/telemetry`) and carries **no privileged content** — only `{ feature, phase, surface }` from a versioned feature taxonomy, the same structural allowlist as every other event. **Consent is always-on, opt-out** at two levels: per-firm `usage_analytics.enabled` (default true) and per-user `member.opted_out_of_usage_analytics`, both resolved at emit time off the hot path via a cached resolver — mirroring the diagnostics setting. **Identifiers are pseudonymous:** `firmId`/`userId` are HMAC-pseudonymized under a server-held pepper before any write and **fail closed** (a missing pepper drops the event); plaintext identifiers never reach the dataset. **Queries are cross-firm aggregate only** with small-n suppression (`k = 5`) — a cell from fewer than five distinct firms is suppressed and its count reported, never silently hidden. Live aggregate counts run on the **Analytics Engine `usage` dataset** (the MVP path); full-fidelity per-firm/per-user analytics (funnel, retention, dead-feature by distinct users) run over the shared **Iceberg tier** (ADR-0056) once the **Logpush → Pipelines → R2 Data Catalog** step is provisioned. **Realizes ADR-0056** — the telemetry analytics / Iceberg tier moves from _deferred_ to _adopted_ (a trigger has bound: full-fidelity retention/BI for usage). **Deferred seams:** the **client beacon** for pure-client surfaces (no client traffic yet) and the Logpush→Pipelines Iceberg build (a Cloudflare-infra step). **Scope/isolation:** reads only redacted cross-firm aggregate telemetry — never per-firm privileged data — staying clear of the ADR-0003 boundary; gated reads follow ADR-0068. **Considered & rejected:** opt-in (under-samples honest usage and defeats the dead-feature signal); per-firm customer dashboards (different audience and cardinality — out of scope); a separate analytics pipeline (violates the one-logging-path rule). **Consequences:** usage signal accrues from day one at near-zero marginal cost on the existing path; the cost is carrying the pepper secret, the consent resolver, and the deferred Iceberg/beacon seams. Extends **ADR-0017**/**ADR-0038** (observability); realizes **ADR-0056**; bounded by **ADR-0003** (tenancy) and **ADR-0068** (access control); reuses **ADR-0078**/**ADR-0083** (metering + load-profile accretion).
