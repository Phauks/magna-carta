**Messaging (SMS/MMS/RCS) + voice/telephony via a CPaaS behind plugin ports; Telnyx launch adapter; transcription in-house on Cloudflare Workers AI; self-hosted gateway rejected.** **Context:** the _Communications layer_ was email-only, but notifications, the SMS 2FA factor (ADR-0004), e-signature/portal access codes (ADR-0045/ADR-0036), the formerly-backlogged "client texting," and a new **receptionist call-intake** workflow (transcribe inbound calls → call log + intake capture) all need text and voice channels. The owner's instinct was to self-host for control. **Decision:** add two typed **category ports — `messaging` and `telephony`** — under the uniform plugin model (ADR-0015): each adapter is its own isolated Worker with per-firm scoped secrets, signed inbound webhooks, delivery receipts, and opt-out state. (1) **CPaaS, not self-hosted.** Self-hosting the carrier is rejected — SMS/MMS require a registered aggregator, **RCS exists only through Google's RBM + carrier agreements (cannot be self-hosted)**, and an SMPP gateway (Jasmin, Apache-2.0) is an off-Cloudflare persistent Python/Twisted+Redis+AMQP host that fights the Workers/D1/R2 model (same reasoning that rejected Documenso/self-hosted-Sentry and hesitates on Fider's host). Control comes from the **swappable adapter + isolation**, not from owning the carrier; Jasmin is kept only as a documented fallback. (2) **Launch adapter: Telnyx** — owns its private IP network (voice quality/latency for the receptionist line), lowest published SMS cost (~$0.004/segment), one number inventory spans **SMS/MMS/RCS + voice**, exposes **bidirectional WebSocket media streaming** (clean fork into transcription), and signs webhooks with **Ed25519** (public-key verification in a Worker, no shared secret). Swappable behind the port: **Twilio** (turnkey fallback, most mature RCS GA), **Bandwidth** (owned Tier-1 US voice + E911 strength), **Plivo** (cost at scale). Same "launch adapter, swap in days" posture as Payments' Helcim (ADR-0032). (3) **Transcription in-house on Cloudflare Workers AI** (Whisper / Deepgram Nova-3), **not** the carrier's hosted transcription — privileged call audio never egresses (same confidentiality logic as in-house file conversion, ADR-0030, and no-third-party-error-SaaS, ADR-0038); one capability also serves the deferred transcript-sync (ADR-0029) and discovery media (ADR-0012). (4) **OTP stays in Better Auth** (ADR-0004); the port only _delivers_ the code — no vendor "Verify" product (one OTP path, no lock-in). (5) **Compliance invariants live in the ports:** **A2P 10DLC / toll-free / RCS-brand registration** is a procurement prerequisite (TCR fees, weeks of lead time — same class as the legal-research connector entitlement, ADR-0015); **TCPA consent + STOP/HELP opt-out** enforced in the messaging port; **call-recording consent** gated by the existing jurisdiction-profile machinery (ADR-0009 trust rules / ADR-0032 surcharge legality — Nevada one-party, ~12 states all-party), reused not rebuilt; **E911** seamed (inbound intake line sidesteps it; a real outbound office line triggers it — Bandwidth's strength). **Considered & rejected:** **self-hosted SMPP gateway (Jasmin)** — off-Cloudflare host, cannot do RCS, no real independence (kept as fallback only); **vendor Verify/OTP products** — duplicate the Better Auth OTP path and add lock-in; **carrier-hosted transcription** — egresses privileged audio. **Infobip** dropped from launch (sales-gated, no self-service eval); Sinch/Vonage kept as later port-swap options. **Consequences:** the _Communications layer_ becomes three channels (email + messaging + voice) behind one trigger engine; "client texting" leaves the backlog; intake (_Client intake / CRM_) gains a call-log/transcript input; carrier choice is reversible in days. Cost: A2P/RCS registration lead time and per-message carrier surcharges, and a media-stream→Workers-AI path to build for live transcription. Extends **ADR-0015** (plugin model); touches **ADR-0004** (SMS 2FA), **ADR-0009**/**ADR-0032** (jurisdiction-config reuse), **ADR-0029**/**ADR-0012** (transcription consumers), **ADR-0036**/**ADR-0045** (access codes).
