**Route-metadata model + enforcement chokepoint — every route declares machine-readable metadata (`operationId`, `surface`, `authenticated`, `permission`, `resource`, `audited`, `idempotency`, `rateLimit`, `tags`, `deprecated`; reserved seams `cache`/`planTier`/`metered`); one chokepoint middleware enforces tenancy → authn → RBAC + ethical-wall → idempotency → rate-limit (404-not-403); metadata is emitted as OpenAPI `x-mc-*` extensions so conformance fitness functions assert over the contract; the route table is a registry.** **Context:** _Architectural integrity & coherence_ (ADR-0051) requires cross-cutting concerns to be properties of a traversed path, not steps to remember, and anticipates a route registry; ADR-0063 (idempotency) and ADR-0017/0038 (audit) already assume per-route declarations exist; the RBAC follow-up (ADR-0004) needs a seam to plug into. **Decision:** (1) **Core metadata** per `createRoute` (the field set above); the filter for inclusion is "consumed by the middleware, a fitness function, or codegen" — nothing else. (2) **Reserved seams** declared-not-enforced (design-for-the-superset): `cache`, `planTier`/`featureFlag`, `metered`. (3) **One chokepoint middleware** runs a fixed order: resolve session → firm (ADR-0003) → authn (401 if required+absent) → **RBAC permission + ethical-wall** (404-not-403, ADR-0052; matter-scoped only when `resource` says so) → idempotency (ADR-0063) → rate-limit → dispatch; audit + outbox ride the DAL write. (4) **Emitted as `x-mc-*` extensions** so **conformance fitness functions** (ADR-0051, robust tier) assert structurally: every mutating route is `audited` + names a `permission` that exists in the RBAC registry; money/trust routes require idempotency; no route silently public; surfaces never mix; `operationId` unique. (5) **Deliberately out** (owned by a better-placed chokepoint, to stop the registry rotting): PII (`protected()`, ADR-0026), async external effects (outbox, ADR-0064), notification raises (audit/write seam, ADR-0059), CSRF (derived from `surface`). **Considered & rejected:** **per-handler discipline** (the memory-tier failure ADR-0051 forbids); **a kitchen-sink metadata bag** (rejected via the consumed-by filter); **403 for unauthorized** (an existence oracle — 404 per ADR-0052). **Consequences:** the API's whole security/coherence posture is declared, enforced at one seam, and provable in CI; the `permission`/`resource` fields are the clean handoff to the RBAC spec (capability set, role→permission matrix, ethical-wall mechanics, `portal` external-principal assurance). Reuses **ADR-0051** (registry/chokepoint/fitness), **ADR-0003** (tenancy/DAL), **ADR-0052** (404-not-403), **ADR-0063** (idempotency), **ADR-0017/0038** (audit/Error-ID), **ADR-0026** (`protected()`), **ADR-0059** (notifications), **ADR-0064** (outbox); built on **ADR-0066** (library). Detail in the _API contract & route conventions_ spec.
