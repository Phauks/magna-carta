**Matter-numbering engine: an ordered segment template whose counter scope is derived from the template itself — any segment may be marked _scoping_ and the sequential counter resets per distinct combination of rendered scoping values, allocated from one `matter_number_counter(scope_key, next_value)` table inside the matter's own atomic write batch; numbers freeze as text at assignment; manual entry/renumber are permission-gated actions; numbers are drawn at Open, not at Prospective creation.** **Context:** ADR-0007 fixed "configurable numbering" without an engine design; the owner's requirement (design cycle, 2026-06-11) is that firms reproduce their existing proprietary formats from day one and survive scheme changes without renumbering old matters; a format survey (Clio, esilaw, Dye & Durham, Lawmatics, federal-court formats — research doc section E + design-cycle survey) found year/sequence, client-matter (`10034-00012`), office and practice-area prefixes, attorney initials, date-opened, and court-assigned numbers all in active use. **Decision:** segment kinds `literal` · `counter` (pad width, configurable start — migration continuity) · `year` (2/4-digit) · `date_opened` · `location_code` (ADR-0031) · `matter_type_code` · `client_code` · `staff_initials` · `client_name`; rendered numbers are URL-safe (white-paper constraint) and UNIQUE per firm (bounded-retry idiom, ADR-0062, backstopping the in-batch counter increment); scheme edits affect only future matters; one active scheme per firm stored as per-firm data surfaced through the ADR-0040 Settings registry with a live-preview renderer shared between settings UI and assignment; per-matter-type scheme overrides and per-client scope (needs stable client identity, slice 1·3) are named seams. **Considered & rejected:** fixed scope enums (`{firm}` / `{firm,year}` / `{firm,location}` tables — every new scope a migration; the derived scope_key buys all scopes with one column); renumber-on-scheme-change (firms keep historic numbers — owner-stated); numbering at Prospective creation (dead consultations would burn numbers and wrong-year them — see ADR-0080). **Consequences:** every surveyed format reproduces; the counter table never changes shape; Bates numbering stays explicitly separate (Phase 5). Refines **ADR-0007**; builds on **ADR-0062** (bounded retry), **ADR-0040** (settings surface), **ADR-0031** (location segment).
