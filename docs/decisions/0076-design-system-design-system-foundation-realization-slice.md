**Design-system foundation realization (slice 0·7a) — supersedes ADR-0028, keeping its architecture and replacing one layer: tokens are spec-pure DTCG 2025.10 with the Resolver module for theming (curated theme gallery × light/dark as resolver contexts — the legacy `$extensions.mode` pattern is dead), generated by Terrazzo 2.x (pinned exact) to CSS custom properties + the Tailwind v4 `@theme` plugin; the component layer is an in-house styled layer built directly on Bits UI v2 (shadcn-svelte replaced — its look lives in vendored class strings, not CSS variables, so escaping it converges on headless-build cost while adding permanent fork maintenance, and its fixed `--primary`-pair vocabulary conflicts with the richer semantic token tier; its source stays an uninstalled reference corpus); the catalog is Storybook 10 (Histoire dead — resolves ADR-0028's "Storybook/Histoire"), whose stories triple as Vitest browser-mode behavior tests and per-story axe checks; visual regression is Playwright screenshots across every theme×mode in the pinned Docker image (Argos CI the named upgrade).** **Theming model:** the firm picks the theme from the gallery (launch: one flagship + two-three showcase themes, every theme shipping light + dark), each user picks light/dark/system; applied as `data-theme` + mode class on `<html>` — themes are pure data, adding one is a new resolver input. Single launch density with `density.*` semantic aliases as the future-axis seam; arbitrary per-firm brand palettes designed-for via the Culori OKLCH generation script (built to author the gallery) but not productized; `contrast` resolver axis reserved. **Token gates:** golden-file CSS snapshots (generator-swap insurance), a WCAG 2.2 contrast gate over every theme×mode (APCA advisory only), an every-theme-defines-every-token completeness check, and a spec-purity check — these conditions are what make Terrazzo's bus-factor-1 acceptable (abandonment = rewrite one emission layer in days; Style Dictionary v5 is the named escape hatch, re-evaluated when its unshipped resolver support lands). **Component-layer discipline:** semantic component classes in a CSS layer fed exclusively by token custom properties (wrappers carry structure + `data-[state]` styling — "no off-token values" becomes mechanically lintable); variants as plain typed functions (tailwind-variants churned three breaking majors in nine months; class-variance-authority frozen — any DSL adopted later lands pinned behind one internal module); one internal floating/presence wrapper (Bits v2 forceMount transition pattern + the unstyled-wrapper Floating UI rule); z-index as a token scale (raw `z-*` numerals banned); tailwind-merge extended with every token namespace. **Satellites:** svelte-sonner (toast; Bits ships none), virtua (virtualization — TanStack Virtual's Svelte adapter abandoned), TanStack table-core behind a thin in-house Svelte 5 adapter (official v9 adapter adopted when stable; AG Grid reserved), paneforge (panes), `@internationalized/date` (its `CalendarDate` = the ADR-0055 civil date; feed it, never `ZonedDateTime`), `@lucide/svelte` deep imports only, superforms + formsnap with Standard Schema as the field-layer contract. Bits UI's maintainer gets a recurring sponsorship (load-bearing dependency, half-met funding goal); bits-ui + svelte pinned and upgraded as a pair; week-1 spike: Dialog scroll-lock vs the platform's strict CSP `style-src` (open bits-ui #1995). **Slice split:** 0·7a = this foundation; 0·7b = auth UI + passkeys + the client-reporter/diagnostics surfaces, designed separately as the first consumer. **Rejected:** Ark UI Svelte (credible Zag architecture, but one year old, ~3k weekly downloads, missing Command/Menubar/TimeField — revisit 12–18 months, à-la-carte adoption open); Style Dictionary today (resolver support unshipped; `$themes.json` interim = deeper lock-in); hand-rolled generator (2–4k lines of color-science correctness owned forever); no-DTCG hand-authored `@theme` CSS (the theme×mode matrix becomes unvalidated by construction); Skeleton/Flowbite/Carbon/daisyUI/Melt next-gen (own design language / weak a11y / wrong stack / no behavior / stalled pre-1.0); per-user theme choice (theme is firm identity; the user keeps mode); density toggle and broad firm customization at launch (the homogenization-pain generators this slice exists to prevent — each left a named seam).
