# UI & design conventions

**Status:** Stub — to be written alongside the slice 0·7a build (design: [`docs/specs/2026-06-10-design-system-foundation-design.md`](../specs/2026-06-10-design-system-foundation-design.md); ADR-0076).

**Scope (single home for):** how UI is built so it stays consistent — icon usage, design-token usage, component composition, and the rules that prevent CSS drift.

**Authoritative context:** the [white paper](../Magna-Carta-White-Paper.md) — _Design system & UI consistency_ (the four enforced layers) and ADR-0076. This file is the _practitioner's how-to_; the white paper is the rationale and decision.

**To document (per the slice 0·7a design):**

- **Lucide icons only; no emojis** — deep imports (`@lucide/svelte/icons/…`) only, sizing tokens.
- **Design tokens** authored as spec-pure DTCG 2025.10 (resolver-based theming), generated by Terrazzo to CSS custom properties — how to add/change a token, how to author a gallery theme (the Culori generation script); never use raw values.
- **Tailwind v4** `@theme` setup consuming only generated tokens; what fails lint (`p-[13px]`, raw colors, raw `z-` numerals).
- **`@magna-carta/design-system` components** are the only building blocks (styled in-house on headless Bits UI v2); how to compose; no `bits-ui` import outside the package; when (rarely) to add a new component and the review gate (shadcn-svelte source as the uninstalled composition reference).
- The **design language + page archetypes** — where they live, how a new screen picks an archetype and its state set.
- Component definition of done: a **catalog entry** (Storybook, definition/review), **behavior tests** (stories run via the Storybook Vitest addon), **accessibility** (per-story axe + the batch screen-reader pass), and **visual-regression** (Playwright screenshots across every theme×mode) — appearance _and_ behavior. See [`testing.md`](testing.md).
- Theming: the firm theme setting + the user mode setting; light/dark/system; how the gallery grows; future per-firm branding via the generation script.

> The "tokens + components only" and "Lucide only / no emojis" invariants are summarized in the root [`CLAUDE.md`](../../CLAUDE.md).
