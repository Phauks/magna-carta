Every download registers, on the owner's ruling of 2026-09-16: `bundle` and `conversion` are
already in the schema's producer vocabulary and have simply never been written, and a single matter
file becomes a fourth producer. A file row is a new `reference` KIND rather than an artifact, which
is the security point — an artifact re-download presigns a stored object key with no re-check of
matter access, which is right for a frozen bundle and wrong for a live matter file. Retention
splits: the bytes keep the seven-day rule, the ROW is kept, so the sweep stops deleting and marks
instead. The Downloads screen moves onto `DataTable.Grid` with a column model, so a reader chooses
what they see.
