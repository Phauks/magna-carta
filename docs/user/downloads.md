# Downloads

Anything the platform makes for you gathers under **Downloads**, so you can take it again without
running it a second time. Exported reports go there automatically the moment you download one.

There are two ways in. The **download button in the top bar**, beside the timer, marks itself when
something new arrives; clicking it shows what you have made recently and links to the full list.
**Downloads** in the sidebar opens that full list directly.

Taking something from the top-bar panel gives it back in the format you took it as. The full page is
where you can choose a different one.

Each item is held for **seven days** and then clears itself. The list shows what it is, where it came
from, which formats you have already taken, when you made it, and the day it stops being available.

## Taking something again

Use **Download** on any row.

An exported report can be taken in **any** format, not only the one you chose the first time — the
report itself is kept rather than the file, so the same figures are available as Excel, Word, PDF,
CSV, or plain text. The figures are exactly as they were when you ran it: an export you took on
Monday still reads Monday's numbers on Thursday, which is what makes it worth keeping.

A file the platform assembled for you, such as a bundle of documents, downloads directly through your
browser, so your browser's own download manager handles pausing, resuming, and the transfer speed.

## Clearing the list

**Remove** takes an item off your list straight away. For an exported report this also deletes the
copy the platform was holding. For an assembled file it removes your row and leaves the file to
expire on its own schedule, since a colleague may have asked for the same one.

## What this list is, and what it is not

Your list is **yours**. Colleagues do not see what you have exported, and you do not see theirs.

It is a short-term shelf, not a record. It answers "what did I make recently, and can I have it
again", so items leave after a week. If you need to keep something permanently, save the downloaded
file where your firm keeps its records, or file it to the matter it belongs to.

If an item has passed its date, taking it again will tell you so plainly. Run the report or the
download once more from the screen it came from, and the new copy appears here.
