# Exhibits

Exhibits are the documents you attach to a filing, put in order and labelled Exhibit A, B, C. Find
them on a matter under **Record**, then **Exhibits**.

A matter can have several exhibit sets, one for each filing: the exhibits to a motion, a trial
exhibit list, the exhibits to a declaration. The sets are listed on the left. The set you choose
opens on the right as a table.

## Starting a Set from a Folder

The quickest way is to gather the documents in a folder first.

1. In the matter's **Files**, right-click the folder and choose
   **Make Exhibits**.
2. The new set opens on the Exhibits page. It is named after the folder. Each file in the folder
   becomes an exhibit, in name order, and is titled with the file's name without its extension.

Only the files directly in the folder are used, not the files in folders inside it. A file that is
still being checked for safety, or that failed the check, is left out until it is clean.

Until the set is marked as filed, it keeps up with the folder. Each time you open the set, files you
have added to the folder join at the end and files you have taken out leave. The order you arranged
is kept. To check again while the set is open, choose **Bring Up to Date with Folder** from the set's
"..." menu.

## Starting a Set by Hand

Press **New Set** at the top of the matter. Give the set a name and press **Start Set**. To follow a
folder from here instead, press **Follow a Folder** and choose it.

To add documents to a set, press **Add Exhibits**, tick the files you want, and press **Add**. Files
already in the set are not offered again. A file that is already an exhibit in another set on this
matter keeps the same title in both sets.

## Putting Exhibits in Order

The label comes from the order. The first row is Exhibit A, the second is Exhibit B, and so on. You
never type a label.

To move an exhibit, drag the handle at the start of its row. You can also use the row's "..." menu
(**Move to Top**, **Move Up**, **Move Down**, **Move to Bottom**), or focus the handle and press Alt
with the up or down arrow.

A move is not saved straight away. A yellow strip lists every label the move changes, for example
"Lease Agreement C to A", and each moved row shows the label it had. Press **Save Order** to keep the
new order, or **Undo** to go back. This matters because any document that already cites "Exhibit C"
will be wrong once C becomes A.

To take an exhibit out of a draft set, choose **Remove from Set** from its "..." menu. The labels
after it move up.

## Numbering

The button beside the set's name shows how it is numbered, for example "Exhibit A, B, C". Press it
to change the numbering:

- **Style**: capital letters, small letters, numbers, or capital or small roman numerals.
- **Word**: the word before each label, usually "Exhibit". Leave it empty to show the label alone.
- **Start At**: where counting begins. A defendant's exhibits might start at 500.
- **Prefix**: optional, for example "P-" to get "Exhibit P-1". Press **Add Prefix** to set one.
- **After Z**: for letter styles, what follows Z. Either doubled letters (AA, BB, CC) or
  AA, AB, AC.

The buttons under **Start From** fill in common schemes. You can still change any part afterwards.

## Marking a Set as Filed

When the set has gone out, press **Mark as Filed**. Say how it went out (filed, served, exchanged or
lodged) and on which day, then press **Mark as Filed**.

**This can't be undone.** The labels, titles and file versions are kept exactly as they are at that
moment. After that the set cannot be reordered, renumbered or added to, and it stops following its
folder. In the list on the left, a filed set shows a lock and the day it went out.

If an exhibit is withdrawn after the set has gone out, choose **Withdraw** from its "..." menu and
give the reason. The exhibit keeps its label and stays in the table, marked withdrawn, and no other
exhibit takes its label.

## All Exhibits on This Matter

Below the sets, **All exhibits on this matter** lists every exhibit on the matter once, with the label
it has in each set it belongs to.

## Who Can Do What

Starting sets, adding, ordering and numbering exhibits needs the **Manage exhibits** permission.
Marking a set as filed and withdrawing an exhibit needs the **Issue exhibits** permission. Anyone who
can open the matter can see its exhibits.
