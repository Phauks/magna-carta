# Translate

Translate turns text in one language into another with Google Translate. You can use it two ways:
on the **Translate** screen, or with the **Translate** button under a text message, a note or an email.

## The Translate screen

Find **Translate** in the sidebar's Tools.

1. Paste or type the text in the left box.
2. Pick the language to translate **to** above the right box. The language **from** starts as
   **Detect Language**, and Google works it out. Once a translation runs, the field shows what it
   found. Pick a language yourself if the detected one is wrong.
3. Press **Translate**, or Ctrl+Enter (Cmd+Enter on a Mac).

Each paragraph comes back in the same order, so the translation lines up with the original.
**Copy** copies the whole translation. **Clear** empties the left box. The arrows between the
languages swap them and translate the result back.

**Matter** at the top is optional. It records which matter the translation was for in the firm's
log. Nothing is filed to the matter.

One translation takes up to 20,000 characters. For something longer, translate it in parts.

## Translating where you are reading

A **Translate** button sits under:

- the message in a text, in the call and text window
- a saved note, in the note window
- the body of an email, in the File Workbench's email view

Press it and the translation appears underneath, in the language you last translated into. Change
the language with **To**, and press **Hide** to put it away. If the text changes, the translation
is put away, because it no longer matches.

## What happens to the text

The text you translate is sent to Google Translate, and every translation says **Powered by Google
Translate**, with a link to Google Translate itself. Magna Carta keeps no copy of the text or the
translation. The firm's log records that a translation happened: who ran it, when, the languages,
how many characters, and the matter if you chose one.

A translation from Google can be wrong in ways that read well. It is not a certified translation.

## Who can translate

Every default role can translate. An administrator can take it away from a role in **Settings >
Roles**: it is **translation** under Tools (`tools:translation`).

If the screen says translation is not set up, Google Translate has not been connected for your
firm's Magna Carta yet. Ask your administrator.
