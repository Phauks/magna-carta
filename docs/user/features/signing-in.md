# Signing in and out

Signing in is how you get into Magna Carta. It asks for your email address and password together, and — if your account uses an authenticator app — a six-digit code. Signing out is how you end a session on the computer you are at.

## What it does

The sign-in screen takes you through up to two short steps:

1. **Your email address and password.** Both on one screen, so a password manager can fill them in one go.
2. **Your authentication code**, if your account has an authenticator app set up. This is the six-digit code your authenticator shows, which changes every 30 seconds.

Two tick boxes decide how much you will be asked next time:

- **Keep me signed in on this device** (on the first screen, ticked by default) keeps you signed in on this computer between visits instead of ending your session when you close the browser. Leave it unticked on a shared or public computer.
- **Don't ask for Two-Factor on this device for 30 days** (on the code screen) skips the authenticator code on this computer for the next 30 days. Your password is still required every time. Only tick it on a device that is yours alone.

These two are different dials, and you can use either without the other. The first is about how long this device stays signed in; the second only skips the code step.

**Where accounts come from.** Most people are invited: your firm's administrator sends you an invitation, and you redeem it with a code, your surname and your date of birth. If you are starting a firm of your own, you can create the workspace yourself. Either way the door is [Joining Magna Carta](joining-magna-carta.md), which you reach from the **Register** link beside the email field.

## Common tasks

**Sign in**

1. Enter your email address and password, then select **Sign In**.
2. If you are asked for a code, open your authenticator app, type the six digits it is showing, and select **Verify Code**.

You can paste a code instead of typing it — paste into the first box and all six fill at once. On a phone, the code your authenticator or messages app offers will fill the whole field in one tap.

**Show your password as you type it**

Select the eye button inside the password box. Select it again to hide the password. Use this if a long or complex password is not being accepted and you want to check what you have typed.

**Sign in when you cannot reach your authenticator**

Select **Use a recovery code** on the code screen. Recovery codes are the one-time codes you were given when you set up your authenticator; each one works once, and the field accepts letters as well as numbers. If you have neither your authenticator nor a recovery code, contact your firm's administrator — they can reset two-factor after confirming who you are.

**Go back a step**

Each screen after the first carries a **Back** link above its heading. Going back from the code screen returns you to the sign-in screen and clears what you had typed.

**Reset a forgotten password**

Select **Forgot Password**, next to the password box, or ask your firm's administrator to send you a reset link.

**Sign out**

Select your initials at the top right, then **Sign out**. The initials are on every workspace screen; Account Settings and the other full-screen surfaces show only the Magna Carta mark and a **Close** button, so close out of one of those first. This ends your session on the computer you are using and returns you to the sign-in screen; nothing you were looking at stays behind in the browser. Signing out on one computer does not sign you out on your others — [Signed-in devices](signed-in-devices.md) is where you do that.

## Tips and edge cases

- **"That email and password combination doesn't match our records."** This one message covers every reason a sign-in was refused — a wrong password, a mistyped address, or an account that is not active yet. It is deliberately not more specific: a message that said "no such account" would let anyone test which addresses belong to your firm. Check both the address and the password, and contact your administrator if it keeps happening.
- **"That code didn't verify."** Authenticator codes change every 30 seconds. Wait for your app to show a fresh code and enter that one. If codes are consistently rejected, your device's clock may have drifted — check that its time is set automatically.
- **"That code didn't match. Each code works once."** A recovery code you have already used will not work a second time. Use the next unused code on your list.
- **"Too many attempts."** Repeated tries are slowed down deliberately. Wait for the countdown on the screen, then try again — or ask your firm's administrator, who can unlock you sooner.

Below a failed attempt you will sometimes see how many tries you have left. That count is shared across all three steps: the password, the authenticator code and the recovery code draw on the same allowance, so switching to a different one does not give you a fresh set. When it runs out, the screen shows a countdown instead of a rejection — at that point whether the last thing you typed was right has stopped mattering, and the countdown is the only way forward.

- **The web address never changes** as you move between the steps. That is on purpose: it keeps the fact that your account uses an authenticator out of your browser history and off the screen.
- **Refreshing the page starts over** from the sign-in screen. Nothing you typed is kept, which is what you want on a shared screen.
- **After you sign in** you land on your home page — or, if you followed a link into Magna Carta before signing in, on the page you were trying to reach.
- **"You could not be signed out — your session is still open."** The sign-out did not go through, so you are still signed in and the screen deliberately did not pretend otherwise. Try again. If you are on a shared or public computer and it will not go through, close the whole browser rather than walking away from it.
- **Closing the tab is not signing out.** If you ticked **Keep me signed in on this device**, your session is still there when the browser is reopened. On a computer that is not yours alone, sign out.

## Related features

- Your account's password and authenticator settings live under **Account → Security**.
- Every computer and phone signed in as you, and how to sign out of them, is [Signed-in devices](signed-in-devices.md) — **Account → Active Sessions**.
- Administrators invite new users and set their access under **Settings → Users**.
