# Opening files

Double-clicking a file, pressing Enter on it, or choosing **Open** are one gesture. What that
gesture does is decided by the kind of file, and **Settings › Documents › Opening Files** lists
the decision for every kind the platform knows.

## The page

The page is a table in six parts, one per way a file can open:

- **Browser Editor**: the office editor that runs inside the application. Word-processing
  documents, spreadsheets, presentations and drawings open here, including the older and less
  common formats the editor itself accepts (WordPerfect, Lotus 1-2-3, Keynote, Pages, Numbers,
  Visio and others). The document stays in the firm's storage, and every save is a new version.
- **Text Editor**: the application's own editor for plain text and code. Plain text opens here
  rather than in the office editor.
- **PDF Reader**: the platform's own reader. Nothing here can change a PDF.
- **Preview Panel**: images, audio, video and email messages open beside the file list. Where a
  format cannot be shown, the panel says so and offers the download.
- **Opens Into Itself**: an archive opens as a folder, listing what it holds.
- **Download Only**: programs and installers are never opened in the browser.

Under each part, every family of file is a row with the extensions it covers and, where it
matters, a note on where the list comes from.

## What you can change

Nothing yet. Every kind of file opens one way, and the page states it. The page is built as a
routing table so that when a kind of file gains a second way of opening, the choice is made here.

## What it means for members

A member does not need this page to open a file. They see its effect: a spreadsheet opens in the
editor the way a document does, a PDF opens in the reader, and a photo opens in the preview. When
a member asks why a file opened the way it did, this page is the answer.
