# Uploads

Everything you send to a matter shows under **Uploads** — what is going now, and what you have sent
before.

There are two ways in. The **upload button in the top bar** shows what is in flight and marks itself
while something is moving or when something did not go; hovering it says "Uploads". The **upload
icon at the far end of the row at the foot of the sidebar**, beside Downloads, opens the full screen.

## While files are going

Each batch shows the matter it is going to, the folder it will land in, how many files have gone,
the rate, and roughly how long is left. You can leave the screen: an upload does not stop because
you went to look at something else, and the file list underneath shows every file with where it has
got to.

- **Cancel Upload** stops a batch. Files that already landed stay; the rest are not sent.
- **Retry Failed** sends only the files that did not go, back into the same folder, so you never
  have to pick them again.
- **Send the Rest** does the same for files a cancel left unsent.
- **Open Folder** takes you to where they landed.

**An upload lives in the browser tab that started it.** If you close the tab while files are still
going, your browser will ask first — files that had not landed would need to be sent again.

## What you sent earlier

Under **Earlier**, each finished batch is kept: the matter, the folder, when it finished, and every
file in it with how it ended. Open a batch to see its files.

**Any file that landed can be downloaded again from here**, with the **Download** button on its row.
It comes straight from the matter it is filed on, so what you get back is the file itself, not a
copy of it.

The search reads the file names as well as the matter, so a file you sent last week is one query
away even when you have forgotten which matter it went to.

**This list is kept by the browser you uploaded from**, so it follows the computer rather than your
account — a batch you sent from the office will not appear on your laptop at home. **Clear History**,
in the menu beside the page's title, empties it, and **Clear** empties one batch. Neither removes anything from a matter: the files stay
exactly where they landed.

## Files that did not go

A file that failed says what failed, on its own row. The usual causes are a file the firm's storage
refused and a connection that dropped partway; both are worth one **Retry Failed** before anything
else. A file marked **Skipped** was left out on purpose because the folder already held one with the
same name and you chose not to send it.
