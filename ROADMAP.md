### Hardening (seamed now, executed when upstream is ready)

- **Untrusted file handling (sandboxing + malware scanning)** — uploaded bytes (File Manager, _Client portal_, _Discovery_ ingest) are untrusted; a malicious file is inert at rest, so risk arises only on **process / serve / forward**. **Primary defenses are structural and built anyway** with conversion + preview, tracked in their feature homes — not deferred: **(1) sandbox-hardened processing** (no-egress `enableInternet=false`/allowlist, least-privilege-per-job, ephemeral Containers, resource caps — _Performance & concurrency model_) defeats server-side RCE in our native parsers (the only threat aimed at _us_); **(2) safe delivery** (separate cookieless sandbox origin + CSP + `<iframe sandbox>` + safe-rendition preview, never raw active formats — _Inline file preview_) defeats stored XSS. Per-firm isolation caps cross-tenant blast radius. **Malware scanning is the thinner, deferred layer** (mainly downstream-recipient protection + compliance/cyber-insurance), built as a **swappable port now, engine later** — _borrow outside expertise, never outside custody_ (commercial engine on our own compute yes; data-holding SaaS no, per ADR-0030/ADR-0038). Scan pipeline: pre-acceptance gates (size/type allow-list, magic-byte check, decompression-bomb guards) → quarantine-on-arrival (R2 event → Queue; not servable until cleared) → scan (verdict as metadata) → optional CDR rendition (original preserved for evidence) → re-scan sweep on signature updates → **quarantine, never auto-delete** (infected files are evidence; destruction blocked by holds). Engine options behind the port, by data custody: WAF content scanning (edge Layer-0 — detect-only, 50 MB cap, Enterprise, misses direct-to-R2/at-rest); commercial engine in a Cloudflare Container (Sophos/Bitdefender/MetaDefender — single engine fits ~12 GiB/instance); managed in our own cloud account (AWS GuardDuty / bucketAV-Sophos — solves the large-file cap but needs an off-Cloudflare ingest bucket); ClamAV + premium unofficial sigs + YARA (cheap baseline; needs a `cvdupdate` private mirror; falls back behind the ~2 GB cap). Files past the scannable cap get an explicit _unscanned_ policy; desktop (Tauri) local pre-scan is the parity accelerator. Its own ADR — **engine research complete (owner, 2026-06-12; timeline home = slice 2·1)**: [`docs/research/upload-malware-scanning.md`](docs/research/upload-malware-scanning.md) adopts a self-hosted detection-only MVP — **ClamAV (socket-driven from Rust; freshclam/Talos signatures) + yara-x (pure-Rust; YARA-Forge-Core rules) + our own Rust structural heuristics (lopdf for PDF; cfb/zip/quick-xml for Office)** in a Container behind the port, freely-updated public rule feeds (no rule-writing by us), no data-holding SaaS, no CDR at launch (all CDR options eliminated — pdfium/Dangerzone destructive, DocBleach retired, purgo experimental), ~$35–50/mo all-in; ClamAV stays the one C component but isolated in its own process (socket, not FFI). Pipeline shape and the swappable port (launch verdict: explicit `unscanned`) build in slice 1·1 (ADR-0081); the engine itself builds in slice 2·1, where the engine ADR is written. (_Matters and File Manager_.)
- **Async bulk-download jobs** — the ADR-0027/ADR-0082 seam past the live-stream path: very large zip bundles switch to a build-to-R2-artifact job → signed URL, so a dropped connection doesn't waste the whole transfer and the download is retryable. **Research complete (owner, 2026-06-12)** — [`docs/research/async-bulk-download-jobs.md`](docs/research/async-bulk-download-jobs.md): all four knobs resolved — **threshold** (two config knobs `liveMaxFileCount`/`liveMaxTotalBytes`, now driven by retryability not the relaxed 10k-subrequest cap), **job lifecycle** (Durable-Object-coordinated, queue-consumer-Worker build streaming R2→R2 multipart, Container only as the outlier escalation — no standing infra), **artifact TTL/cleanup** (native R2 lifecycle rule on the `bundles/` prefix, ~7-day delete; DO-alarm belt), and **identical-bundle dedup** (per-firm manifest-hash content key `bundles/<hash>.zip`, the DO is the single-flight coordinator). Near-zero marginal cost (free R2 egress). The threshold ships as a config knob in slice 1·1; the **async build is claimed by slice 2·1 (owner, 2026-06-12)**, which already owns the Queue/Container/DO file-pipeline machinery. (_Matters and File Manager_; ADR-0082.)
- **Version-history delta storage** — store superseded document versions as binary deltas instead of full snapshots: re-pack the OOXML ZIP with _stored_ entries (deflate scrambles bytes on a one-word edit, defeating naive deltas), delta with **zstd `--patch-from`** against a keyframed base, verify a roundtrip content hash, swap the IA object — all as an async Queue/Container job at the existing supersede-to-IA hook, latest version always full (_Document versioning & storage tiering_; ADR-0077, designed-but-deferred). The seam is reserved in the slice 1·1 File Manager spec (`storage_encoding` on version metadata; version bytes hidden behind the data-access layer); the pipeline builds in Phase 2 once Collabora editing generates real version churn and the load-profile harness puts numbers on it (golden rule 10 — at IA's $0.01/GB-mo, full snapshots must reach ~100 GB/firm before costing $1/mo).
- **Telemetry analytics tier (Iceberg-on-R2)** — register the redacted Logpush-in-R2 logs as **R2 Data Catalog** Iceberg tables for zero-egress DuckDB/Spark/BI querying, with compaction + snapshot-expiration maintenance (_Observability and diagnostics_ → _Telemetry analytics tier_, ADR-0056 _Proposed_). Analytics Engine remains the MVP path; the seam sits on data already written. Adopt when a trigger binds — retention past ~92 days, exact/unsampled counts, rich joins / external engines, or cost-at-scale — and re-verify the open-beta limits (Parquet-only, ~2 GB/table/hr, orphan-file cleanup) at that point.
- **Post-quantum signature migration** — passkeys/WebAuthn + the PAdES e-signature seal → ML-DSA/SLH-DSA, and a PQC-capable external-KMS-rooted KEK (_Encryption and key management_, ADR-0046). Seamed today via algorithm-versioning; gated on upstream standards (FIPS 204/205/206, COSE, ETSI PAdES, CA support). Verify Cloudflare hybrid PQC TLS is on for every hop and log any plugin endpoint that won't negotiate it.
