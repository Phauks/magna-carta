**The build panel's copy control is the copy symbol, and its repository link is GitHub's mark.**

Copy carried Lucide `clipboard-copy` — a clipboard with an arrow into it, which is the picture of PASTE — so the one control a person reaches for during an incident was drawn as its opposite. It is Lucide `copy`, the two-sheets glyph, everywhere else in the industry.

The repository link carried `git-branch`, which names a git concept rather than the service on the other side of the link. Lucide has no GitHub mark and could not: brand marks are not iconography. So the mark follows the brand-asset track instead of the icon rule — `@magna-carta/design-system/service-marks` is a new, deliberately quarantined home for a third party's own published mark, self-hosted and unaltered, taken in `currentColor` as the monochrome use GitHub's guidance provides for, with a row in `docs/conventions/third-party-trademarks.md` recording whose it is and on what terms. `lint:one-ui`'s hand-drawn-glyph rule learns the second exemption beside the brand mark's, with the reasoning on it.

**Counsel sign-off is outstanding** on that register row (policy 5, the ADR-0090 legal track) — the mark ships behind that flag rather than ahead of it.
