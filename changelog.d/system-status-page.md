**Settings › Versions is now System Status, organised by feature.** The page opens on four counts
(features, deployment, workers, and, for platform operators, errors in the last day). Under them are
tabs for Features, Deployment, Workers, This Firm, Recent Errors and Feature Flags. Each feature reads
Working, Not set up or Not working. A platform operator also sees what a feature that is off still
needs and the steps that turn it on. Recent Errors lists the platform's failures by kind, each with
its newest Error ID. The header chip is now a short panel showing the deployment, any feature that is
not working and your firm's records, with a button to the full page.
