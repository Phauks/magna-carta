**Translate.** A new Translate screen, under Tools, puts pasted text beside its translation, paragraph
by paragraph, in any language Google Translate offers. A Translate button under a text message, a
saved note and an email in the File Workbench shows the translation right there. Every translation
says it is powered by Google Translate. Magna Carta keeps no copy of the text, and every role can
translate unless an administrator takes it away.
