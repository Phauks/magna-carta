The platform's one table now obeys the rulings it was built to carry, and it can group and mark its rows.

Four settled rulings were already contradicted by the table that shipped days ago, all of them in the per-column filter. The set filter's narrow field said "Type to narrow the choices" and the text filter said "Contains…" — both struck, because every ghost text is the FIELD'S NAME and never a description of what to do; each now carries the column's own label. The set filter's select-all was a static checkbox that stated what IS; it is now one control that states what pressing it will DO, reading "Select none" while everything is on and "Select all" the moment anything is off. And the set filter carried a "Clear This Filter" button, which said the same thing that control already says: a set filter with everything selected IS no filter, so it now carries no clear control at all. The other filter kinds keep theirs, and still only while a filter is in play.

A fifth was in the columns menu: an unpinned column's control drew the crossed-out pin, a different glyph for what is meant to be one glyph in two states. There is one pin everywhere the pin state shows — pinned rows and pinned columns alike — and fill is the only difference.

Alongside the conformance work the table gained the two things every list says about a row before it says anything about the row's data. **Row groups:** pinned items sit above everything, separated by a rule, in the order the member arranged them rather than the table's sort — a pinned file leads a list whose folders would otherwise sort ahead of it. A pinned key whose row a filter excluded contributes nothing, so the footer's "n of m" stays true. **Row marks:** one vocabulary — the filled pin on the row's first cell, a dashed edge while a row waits on a cut or a copy (a cut row speaks quieter, because it is leaving), and that same quieter voice for a row present but not of the list's own kind, which is what a deleted match among live search results and an event inherited from a folder act both need.

Every fixed ruling is pinned by a test that asserts the property the ruling names, so the next round finds them asserted rather than remembered. The developer console's table-states gallery gains the groups-and-marks specimen.
