A review surface for where the show-and-hide-a-pane control belongs: `/developer-console/pane-toggle-placements`.

Time, Fees, Costs and Billing each draw a row above their table whose only occupant, most of the time, is one glyph. The row costs a control's height plus the stack gap, taken off a table already fighting for it, and it is spent on a control that is not an act on the records at all. The glyph came from the file manager, where it ends a toolbar the screen draws anyway — the ledgers copied the button without copying the band it stood in.

Every candidate home is rendered from the shipping components over one fixture, at one fixed height, so what each costs the table is the visible difference between two specimens: the row as it is today, the counts strip's inline end, the pane's own edge, the matter's header band, and no toggle at all with the selection opening the pane. Files gets the same treatment — it carries two of these toggles, and is the only screen in the product that lets a reader close its own folder tree, so one specimen simply takes that toggle away.

Nothing has moved yet. The surface exists so the choice is made by looking rather than by describing.
