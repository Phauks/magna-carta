**Soon hovers name what is missing, in plain words.** Every disabled "Soon" control and not-yet-built column now reads "Not built yet: <what is missing>." (for example "Not built yet: recording payments.") instead of naming the internal dependency ("Waiting on the payments slice, whose first step is ..."). About 70 dependency phrases across billing, costs, fees, time, trust, discovery, custodian, matters, reports and the file tools are rewritten; the small "Soon" badge is unchanged, at the owner's request. The rule in `docs/conventions/ui-design.md` records the wording.

## Public

**Clearer "Soon" hints.** Features that aren't built yet now say plainly what's missing, such as "Not built yet: recording payments."
