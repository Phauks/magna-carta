The file list's File Type column shows the file's real extension — "pdf", "docx", "mp4" — instead of a category word we invented for it ("Word", "Video", "Archive"). The extension is what the file actually is; the category was our paraphrase, and the owner ruled the paraphrase out of the file manager. A file whose name carries no extension falls back to the extension its sniffed media type implies, and when nothing is known the cell is blank rather than a placeholder phrase like "Not known yet". Sorting the column follows what it shows, with blank cells sorting after every known type.

## Public

The File Type column in a matter's Files list now shows the file's actual extension — "pdf", "docx", "mp4" — rather than a general category like "Word" or "Video". If a file's type is not known, the column is simply blank.
