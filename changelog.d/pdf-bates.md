**Bates numbering for `@magna-carta/pdf` — `stampBates(bytes, options?)`:** stamps sequential identifying labels onto every page of a PDF. The stamp is an **additive overlay**: a new Helvetica text stream is appended last on each page so it renders on top; no existing text, images, vector graphics, or metadata is removed or modified. Options: `prefix` (label text before the number, default `""`), `startNumber` (default `1`), `padding` (zero-pad width, default `6`), `position` (one of six corners/edges, default `"bottomRight"`), `marginPt` (default `18`), `fontSizePt` (default `8`). Returns `{ pdf: Uint8Array, start: number, end: number, pageCount: number }`. The engine uses base-14 Helvetica (no font embedding required) and adds exactly one shared font object per document regardless of page count. Placement is rotation-aware: labels read upright on pages with any `/Rotate` value (0/90/180/270). Page resources are merged non-destructively — no existing font resource is dropped. Continuous set numbering is supported by threading `result.end + 1` as the next `startNumber`. The WASM binding (`stampBates`) is exposed alongside the existing `redactDocument`, `sanitizeDocument`, and `detectDocument` exports. (`crates/pdf-core`, `packages/pdf`)
