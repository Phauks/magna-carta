Matter Files — a matter's documents now have a screen. The file record the firm keeps is presented four interchangeable ways (a dense list, tiles, a chronological timeline, and a gallery), with a folder tree, a folder path you can link to and walk back out of, and a selection shared across every view. A file still being scanned reads as processing; a file the scanner rejected says so, with its reason, exactly where it was dropped — rather than silently never appearing. The gallery shows files by type and is marked alpha until image thumbnails exist; it does not pretend to preview what it cannot render. Browsing only for now — uploading arrives next.
