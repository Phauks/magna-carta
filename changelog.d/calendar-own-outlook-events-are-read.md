**A member's own Outlook events can be read for them.** A member can now choose which calendars of
their connected account Magna Carta reads, and each sync pass keeps a private copy of what is in
them for a month back and a year ahead. Only that member can read it: there is no route and no
permission that reaches another person's own events. Copies of the firm's events that Magna Carta
wrote to Outlook are left out, so nothing is counted twice. The settings choice and the calendar
screen that shows these events follow in the next change. Dormant until a Microsoft application is
registered.
