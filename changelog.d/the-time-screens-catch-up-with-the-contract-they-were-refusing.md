The time surfaces stop saying "not recorded yet" about eight things the server had been serving all along.

The Time Sheet, the matter Time tab and the shared record window were built whole against a record fuller than the listing answered, and every field the contract could not fill was rendered honestly as a gap — the right call, and each one was written down in a register. What nobody re-asked is whether the contract had caught up. It had, in the same commit that built the Time Sheet. So the entry number, the entered date and who entered it, the resolved rate, both UTBMS codes, the internal memo, the attachment relation and the per-entry event history were all being served while three screens went on refusing them. The web type declared 12 of the 28 fields the server sends, which is what let it last: a type naming a subset is not a smaller truth, it is a screen that cannot see what arrived.

**What is now real.** The **entry number** on the ledger column, the sheet's Time Code cell, the record window's subtitle, the details panel and the printed sheet — and an entry captured before the sequence existed says it has none rather than being given an invented one. **Both dates and both people**, on every row rather than only the delegated ones. The **resolved rate**, read and not typed, naming where in the chain it came from: an entry keeps the rate in force on its work date for ever, so this states a fact rather than offering a change. **Category and Activity** as typable comboboxes over the firm's own UTBMS catalogue, one component rendered twice; a catalogue this account may not read costs the picker and not the field, because the entry's own code and label ride the listing. The **internal memo**, written and saved on the sheet's third row line and in the record window, and shown on a read-only record too — internal is not the same as hidden. Its exclusion from the printed sheet is now proved against a real rendering holding a real memo, not asserted in a comment. **Attachments**: what an entry points at, attaching one of the matter's own documents, detaching without deleting. And the **History tab** reads the served events, translating the audit's own names into a reader's words, reading an unknown event back rather than dropping it, and quoting only a reason somebody actually wrote — the audit's metadata is a field list by construction, and a field list is not prose.

**What is still a gap, and still rendered as one:** moving a written entry to another matter, recording one member's work under another's hand, the review gate as a served setting, unsubmit, delete-draft, billing disposition beyond the boolean, the rounding increment, capture before an entry has a description and a duration, the non-billable category, and the invoice's own number beside its identifier.

The register that got this wrong now says what it is for: a list of gaps is only honest while somebody re-asks it against the contract, and unasked it states the opposite. A test holds the retired eight out of it.
