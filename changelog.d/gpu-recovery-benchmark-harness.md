**Password-recovery GPU benchmark harness — the first step toward cracking modern encryption on rented cloud GPUs.** The file-recovery tool's CPU rung tops out at common-password guessing; modern slow-key-derivation formats (Office 2013+, PDF R6, 7-Zip) need a GPU, which Cloudflare does not rent. A new internal tool (`@magna-carta/gpu-benchmark`) measures real hashcat throughput for every recovery hash-mode on rented [vast.ai](https://vast.ai) GPUs and records the numbers into a committed rig-profiles table — the empirical input that will decide which rigs the production GPU rung rents and how deep it can search. It rents the cheapest verified offer for each candidate GPU, runs the benchmark in an isolated container image (hashcat + our clean-license wordlists, nothing secret), and **guarantees the rig is torn down** even on failure — with a reconciliation sweep that destroys any leaked benchmark instance as a billing backstop. The vast.ai integration is validated against the live API, and the container's own benchmark image is included. The design (rented-GPU rung driven by a Durable Object coordinator, hashcat as the engine, tiered escalation within a dollar-and-time cap, and a hash-only confidentiality boundary that keeps file bytes and client identity off rented hardware) is recorded; wiring the rung into the recover flow, and the first real benchmark run, follow.
