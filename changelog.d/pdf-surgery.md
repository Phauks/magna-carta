**PDF text-preserving redaction — surgery mode for `redactDocument` in `@magna-carta/pdf`:** `RedactionOptions` gains an optional `mode` field (`"flatten"` | `"surgery"`, default `"flatten"`). Surgery mode excises only the glyphs whose centres fall within a redaction rectangle from the page content stream, leaving remaining text on that page as selectable PDF operators. The engine falls back to rasterize-and-reassemble (`"flatten"`) for any page it cannot confirm clear: per-page fallback triggers for pages using standard-14 fonts without embedded width tables, non-Identity Type0 encodings, non-zero page rotation, inherited resource dictionaries, inline images, and redaction rectangles that overlap raster image XObjects. The per-page outcome gate (re-observing glyph positions via the hayro textpos device after the edit) ensures a surgered page is never less safe than a flattened page. `RedactionResult` gains `pagesSurgered` and `pagesFlattened` arrays (0-based page indices) alongside the existing `pagesRedacted`. Over-removal of an immediately neighbouring glyph is the only residual non-safety failure mode. `crates/pdf-core` passes 65 tests. (`crates/pdf-core`, `packages/pdf`)
