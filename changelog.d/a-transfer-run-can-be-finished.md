**A record transfer run can be finished.** A file's column mapping is saved as it is worked on and is there on the next visit, before any pass has run. A column of codes shows how many of the file's own values are matched. The rows a pass rejected download as a file in the source file's own shape, with the reason for each in a first column. A run is ended by accepting it, which asks for a conflicts check of every live matter it brought in, or by stopping it, which keeps what arrived and asks for nothing.

## Public

Record Transfer now keeps the column mapping you are working on, shows how many of a file's codes you have matched, lets you download the rows that were not brought in with the reason for each, and lets you accept a run when it is right or stop it when it is not.
