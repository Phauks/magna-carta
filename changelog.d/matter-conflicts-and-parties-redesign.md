**A matter's Conflicts and Parties tabs now match the conflicts check screen.** Conflicts has four folding sections: Results, Standing, Checks and Re-checks. You can review the latest check's results right there. Parties is a table that shows whether the latest check searched each party, and it flags anyone added since. Counsel's rows name the firm they work at and can add that firm to the matter, so the next check searches it too.

## Public

A matter's Conflicts tab reads like a conflicts check now. Review the latest check's results without leaving the matter, and see every check filed on it. The Parties tab is a table that tells you who the latest check searched and who was added since. On a counsel's row it names their firm, and one press adds that firm to the matter so the next check covers it.
