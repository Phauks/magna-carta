**Five user guides caught up with where the file tools actually are.** Four told the reader to open the Tools sidebar and pick a standalone tool that is now a File Workbench tab (Hash, Metadata, Unlock), and the workbench's own guide still routed through Tools rather than the sidebar. A guide that sends somebody to a screen that no longer exists is worse than no guide.

`attorney-license-lookup.md` is new, and carries the two things the screen cannot say at length: why Magna Carta sends you to the state's register rather than answering for you (standing is exactly the fact that changes after you look, so a stale copy would be worse than none), and what an unencrypted register means for the name you are about to type into it.

## Public

**The help for the file tools now matches the product.** Hashing, metadata and unlocking are tabs on the File Workbench rather than separate tools, and the workbench has its own place in the sidebar, so the guides say so.

There is a new guide for Attorney License Lookup: which register answers for which state, why you read it live rather than taking Magna Carta's word for it, and the two states that publish theirs without encryption.
