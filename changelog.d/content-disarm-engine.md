**A content disarm engine, in Rust: `crates/disarm-core`, shipped to TypeScript as `@magna-carta/disarm`.** It writes a copy of a PDF, an Office package (Word, Excel, PowerPoint, with or without macros), an RTF document or a picture with everything that can act taken out, and reports what that was by kind. PDF loses JavaScript, open and additional actions, launch, submit, import and remote-file actions, non-web links, embedded files, XFA and self-playing media, with pdf-core's guard and attachment scrub run first. An Office package loses its macro project, ActiveX controls, custom ribbon and external workbook links; external relationships other than web hyperlinks are blanked; embedded objects are emptied, and an embedded Office package is disarmed in turn; DDE and include fields are neutralized with their shown result kept, and so are Excel DDE formulas with their cached value kept. A macro-enabled file comes back with the plain extension (`.docm` to `.docx`). RTF loses objects (keeping each one's picture), object data, data stores and dangerous fields. Pictures are decoded and encoded afresh. Every format re-reads its own output and refuses to return a copy that still carries anything it promised to remove. Legacy binary Office files are refused as unsupported. No screen or pipeline stage calls it yet; design in `docs/specs/2026-11-13-content-disarm-design.md`.
