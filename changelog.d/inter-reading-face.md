**Inter is the default reading face.** `font.sans` is Inter Variable (`@fontsource-variable/inter`, OFL); Atkinson Hyperlegible Next becomes a typeface-axis overlay stored as `atkinson-hyperlegible`. The old default's stored `atkinson` is no longer a recognized value, so it falls back to Inter rather than pinning everyone to the face they never chose. The boot script, the Font Family options and the typeface samples follow.

## Public

**A new default typeface, with a plain zero.** The app's text is now set in Inter. Dates and amounts read as numbers again, without the slashed zero. If you preferred the old face, choose Atkinson Hyperlegible under Settings, Text, Font Family.
