The **File Workbench** — one Tools screen where a file that belongs to no matter is dropped once and read every way at once, instead of ten screens each asking for the same bytes.

Type, Hash, Malware Scan, Metadata, Email, Convert, Repair, Text Recognition, Unlock and AI Text are all capabilities of one surface. Two of them are real in the browser today with no backend at all: what the file actually is, read from its leading bytes against what its name claims, and its SHA-256 and SHA-1. The other eight render their own control, disabled, naming what they wait on.

A flagged file still gets everything. The scan verdict is reported on the file's row and in its Overview and gates nothing, because a file somebody does not trust is precisely what this surface is for and the readings a gate would withhold are the ones that answer whether to trust it. A fitness test holds it: every capability is evaluated against the same file under each verdict, and the answers have to be identical.

Conversion acts on the whole selection, and offers only the formats every selected file can reach — a production of sixty scans is one gesture, and a target half the selection cannot become is not offered at all rather than failing partway.

The capability set is a registry of self-contained modules: adding one is a module and a line in an array, and the Overview is contributed by the modules rather than written by hand, so the synthesis cannot fall behind the set.
