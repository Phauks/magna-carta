Five more panels open in `ActionDialog`: the ones the four directory panes compose.

The panes had been excluded from the migration as "panes inside a surface, not modals," a reason that described the files rather than the hits; each pane holds a real form dialog. Assign A Category, Record A Way To Reach Them, Record An Identifier, Change The Name On The Record and Record Another Name are now on the shell, on `LabelledField` and `FieldRow` where they had hand-minted ids, each refusing its commit with a reason where it used to disable silently, and each asking before a stray Escape throws typed work away (the change dialog compares against the name it was seeded with, so an untouched seed asks nothing).

Four allowances leave the registry; six remain, every one a named exclusion. The design records the correction: an allowance's reason should name the panel it excuses, not the file that holds it.
