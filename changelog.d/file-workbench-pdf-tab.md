The File Workbench has a **PDF** tab. It reads a PDF's pages and their size, its form, whether it
needs a password, and any Bates numbers already on its pages, and lists the PDF Editor's tools.
**Open** works on the bench file in the same PDF Editor a matter's PDFs use, and whatever the editor
makes (a redacted, watermarked or protected copy, extracted or split pages, a filled form) goes back
on the workbench as a new file. Nothing is added to a matter. Bates numbering needs a matter's
register and says so on a bench file.
