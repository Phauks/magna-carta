**The file manager now matches the owner's settled Docket design, and Fees stands beside Time and
Costs.** The work-in-progress fee ledger left the Billing tabs for its own matter section, and
Billing (the bill register) wears the Alpha mark instead of Soon. On the Files surface: the
breadcrumb and navigation controls sit directly above the file list rather than spanning the whole
surface, the counts footer is pinned to the bottom of the screen and tallies folders and files with
a select all/none toggle, the New control anchors the toolbar's far end, and the matter's status
seal moved beside the matter number in the masthead's top-left corner. Toolbar and footer controls
are quiet glyphs — no resting box, no grey plate behind a disabled undo/redo, an active toggle
reading through its glyph and a hairline — the columns control included; the file area's edges are
square; the pane dividers lost their grip handles; and both side panels sit on the sunken surface
so they read as panels. Collapsing or reopening a side panel now hands the space to the file list
alone instead of resizing the opposite panel. The folder tree's right-click grew the full file
menu — open, download, pin, rename, cut, paste, delete, colour and mark. Uploading no longer waits
on the destination question: files start uploading the moment they are picked (drag-and-drop onto
the list included), the Upload dialog shows each file's own progress while the destination —
Current Folder, Home, or Select Folder over the real folder tree — is chosen, and a failed upload
now names the stage it failed at and quotes the Error ID.

hand their space to the list when collapsed, the folder tree's right-click carries the full file

destination, and failures that name the stage and quote the Error ID.
