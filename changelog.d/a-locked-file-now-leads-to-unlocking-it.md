**File Unlock & Password Recovery is a real, working tool, and a locked PDF leads straight to it.** The Tools catalog has named this capability for a while over a backend that was fully built and unreachable from any screen; it now has one. Dropping an encrypted PDF, ZIP, or Word/Excel/PowerPoint document onto the File Workbench and choosing Unlock offers exactly the two things the tool has always promised: unlock it with a password you have, or start a search for one you have lost.

Recovering an unknown password is a search that can run for hours, so starting one hands off to its own screen, addressed by the search rather than by the file that started it — leave it, close the tab, come back tomorrow, and the same link finds the same search exactly where it was left. It can be cancelled at any time, and a password it finds is shown once, to the person who started the search.

**Opening a password-protected PDF from a matter no longer just fails.** The reader now asks for the password right there, checks it in the browser without a round trip to the server, and opens the document the moment it is right. A wrong guess says so and lets the reader try again; a reader who does not have the password at all is pointed straight at the recovery tool.

## Public

**A locked PDF asks for its password instead of refusing to open.** Open a password-protected PDF from a matter's Files page and the reader now asks for the password directly — type it and the document opens, checked without ever leaving your browser. Get it wrong and you can try again; don't have it at all, and the reader points you to File Unlock & Password Recovery in Tools, which can search for a common or predictable one.

**File Unlock & Password Recovery, in the Tools sidebar, now actually works.** Drop in a password-protected PDF, ZIP, or Word/Excel/PowerPoint file: unlock it with a password you have, or start a search for one you have lost. A search you start opens its own page you can leave and come back to — it keeps running, you can check its progress, and you can cancel it any time. A password it finds is shown once, so copy it right away.
