**File Analysis is a plain file table, and the file manager's header holds still.** The strip above
the File Analysis table is gone entirely — the Safety column already filters, so a second row of
controls above the table said the same thing twice. The view's own acts moved to the footer beside
undo/redo: the door into the set-aside issues and the report download (the copy button is gone; the
download produces the same text). Browsing inside a zip likewise adds nothing above the table: the
archive's crumb, its badges, the extract seam, and the way out sit on the archive's own line just
above the footer, so entering and leaving an archive never moves the header and never costs the
footer a tool.

## Public

**A simpler File Analysis view, and a steadier file manager.** The row of buttons above the File
Analysis table is gone — filter with the Safety column instead, the same way you filter every other
column. The report download and the ignored-issues toggle now sit in the bottom bar. Opening a zip
also keeps the top of the screen exactly where it was: the zip's name, its folder trail, the
extract control, and the close control appear on their own line just above the bottom bar, which
keeps all of its usual tools.
