**File Analysis is a plain file table.** The severity and issue-kind filter buttons that sat above
the File Analysis table are gone — the Safety column already filters, so a second row of controls
above the table said the same thing twice. What remains in the view's header strip is what only
this view has: the count of findings shown, the door into the set-aside issues, and the two report
actions.

## Public

**A simpler File Analysis view.** The row of filter buttons above the File Analysis table is gone —
filter with the Safety column instead, the same way you filter every other column. The issue count,
the ignored-issues toggle, and the copy/download report actions are unchanged.
