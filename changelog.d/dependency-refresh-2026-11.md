**Every npm dependency is on its newest compatible release, Wrangler is on 4.158.0, and every Cargo lockfile is refreshed.** The catalog in `pnpm-workspace.yaml` moves each pin to the newest release on its own major line that is past the three-day cooldown, including `wrangler` 4.110.0 to 4.158.0 (Worker Previews need 4.135.0 or later), `@cloudflare/workers-types` to `5.20261106.1`, `@cloudflare/vitest-pool-workers` to 0.23.0, `better-auth` to 1.7.18, `zod` to 4.6.7, `svelte` to 5.57.3, `bits-ui` to 2.20.6 and Storybook to 10.6.6. `happy-dom` crosses to 21.0.4, the first release clear of two HIGH advisories (an import-alias escape to host code and an SSRF through parsed iframes and stylesheets). Two overrides are new: `tinypool@2` at 2.1.2 clears two CRITICAL prototype-pollution-to-code-execution records reached through `vite-plus`'s formatter, and `zod` at 4.6.7 reaches the copy the Workers test pool hard-pins at 4.4.3. Upstream bits-ui now restores the body's style through CSSOM, so `patches/bits-ui@2.20.6.patch` keeps only the preventable-`onFocusOutside` half. better-auth 1.7 types the two-factor enrolment answer as a union with an emailed-code shape, which `apps/web/src/lib/account/two-factor.ts` now refuses by name. Svelte 5.57 flags the safe-browse canvas's deliberate `role="application"`, now ignored with its reason beside it. Terrazzo 2.10 writes zero-length shadow lengths more compactly, so `packages/design-tokens/generated/` is regenerated with no change in meaning. `yara-x` moves to 1.23, which requires wasmtime 48, so the accepted `RUSTSEC-2026-0269` entry leaves `osv-scanner.toml`.

**The Rust supply chain crosses the majors that carried advisories.** Every `zip` consumer in `crates/` and `containers/*` moves to 9.4.1, which clears nine zip advisories (several of them CRITICAL: a dual-header parser differential, an AES-entry HMAC bypass, extraction outside the target directory). zip 9 returns entry names as a `Result`, and each call site falls back to a lossy decode of the raw name, so no entry is skipped. `tantivy` 0.27 lifts `lru` to 0.18.5 (RUSTSEC-2026-0253). Also moved: the RustCrypto family (aes 0.9, cbc 0.2, md-5/sha1/sha2 0.11 and the rest, with cipher 0.5's trait renames), `cfb` 0.16, `chardetng` 1.0, `zune-png` 0.5, `tower-http` 0.7, `base64` 0.23, `lopdf` 0.46 and `oar-ocr` 0.9.2. Held, each for a stated reason: `lopdf` 0.47 rebuilds a missing cross-reference table on load and so reports a broken file as intact; `hayro` 0.9 replaces the device trait the bad-redaction detector implements; `quick-xml` 0.42 rewrites the event model under the untrusted OOXML walk; `sevenz-rust2` 0.25 makes private the internals the 7z parser reads; `reqwest` 0.13's rustls feature pulls in `aws-lc-sys`, a C library; `mail-parser` 1.0 needs rustc 1.98; and `rand` 0.10 is held because `ms-offcrypto-writer` takes a rand 0.9 generator.
