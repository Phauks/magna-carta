The host every file capability is run from: `/file-workbench`, a file dropped once and read by all ten. A sidebar destination in the Firm group rather than a row inside the Tools catalogue, because the ten file utilities the catalogue listed are this screen's own capability tabs and the host does not belong filed among the things it hosts; those ten rows are retired, leaving the workbench the whole of the catalogue's `files` group. Two capabilities are real in the browser today — the file's true type, read from its leading bytes against what its name claims, and its SHA-256 and SHA-1. The eight whose engines run in a container render their own control disabled with the dependency named. The capability set is a registry, so adding one is a module and an array entry; the Overview is contributed by the modules rather than written by hand. Conversion acts on the whole selection, and offers only the formats every selected file can reach. Two rounds of owner review are recorded in `docs/conventions/file-workbench-rulings.md`; the second turned the file list into the product's one grid and moved four of its rulings into the standing set.
