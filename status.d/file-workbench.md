The Tools host every file capability is run from: the file-workbench route, a file dropped once and read by all ten. Two capabilities are real in the browser today — the file's true type, read from its leading bytes against what its name claims, and its SHA-256 and SHA-1. The eight whose engines run in a container render their own control disabled with the dependency named. The capability set is a registry, so adding one is a module and an array entry; the Overview is contributed by the modules rather than written by hand. Conversion acts on the whole selection, and offers only the formats every selected file can reach. Five rounds of owner review are recorded in `docs/conventions/file-workbench-rulings.md`. The second turned the file list into the product's one grid; the fifth made the list and the readings one framed instrument, took the provenance rows and the Convert tab's self-description out, collapsed conversion targets to file types, and moved the digest display into the design system as `DigestList`, shared with the matter file's inspector so the product draws that reading one way.
